# 次に試す題材

今回の14題材を読んだ後、無料の条件と必要なドメインを確認してから個別に追加する。

| 順  | 分野                       | 小さな実装案・前提                                                                                   |
| --- | -------------------------- | ---------------------------------------------------------------------------------------------------- |
| 15  | DNS / TLS                  | 独自ドメインをCloudflareへ接続し、DNS only/proxiedと証明書を比較。ドメイン取得費用は無料枠に含めない |
| 16  | CDN / Cache Rules          | 静的オリジンを用意し、zoneのCache RuleとWorkers Cacheの違いを観察                                    |
| 17  | Redirect / Transform Rules | 数個のURL転送とレスポンスヘッダー変更。Freeのルール数内に収める                                      |
| 18  | WAF / DDoS                 | Freeで利用できるルールとログ範囲を確認し、特定パスだけを保護                                         |
| 19  | Tunnel / Access            | ローカルHTTPサービスをTunnelで接続し、Access認証を付ける                                             |
| 20  | Gateway / WARP             | 個人用のテスト端末でDNS許可/拒否。端末ルーティング変更は別途承認して実施                             |
| 21  | Workers AI                 | 無料割当内の短い文章分類。使用モデル・neurons・上限を実装前に確認                                    |
| 22  | AI Gateway等               | 無料機能と外部モデル料金を分け、無料の組合せが成立する場合だけ試す                                   |

Pages、legacy KV DO、新規の非推奨製品は対象にしない。DNS/CDNのzone設定をworkers.devで再現したことにはしない。
